# Appendix C — Screenshot capture guide (for Word/PDF volume)

Use full-window captures at **1280×720** or **1920×1080** for consistent print layout.

| # | Screen | URL / action | What to show |
|---|--------|----------------|---------------|
| 1 | Home | `/` | Hero + cards + footer |
| 2 | Booking search | `/booking` | Form + side panel |
| 3 | Search results | `/booking` after search | Available buses block |
| 4 | Login | `/login` | Form |
| 5 | Register | `/register` | Form |
| 6 | Seat selection | `/book/menu1` | Seats |
| 7 | Payment | `/book/menu2` | Card form |
| 8 | Ticket | `/book/ticket` | Ticket layout |
| 9 | My bookings | `/my-bookings` | Table |
| 10 | Profile | `/profile` | Profile + table |
| 11 | About | `/about` | Sections |
| 12 | MongoDB Compass | local | `busdatas` + `bookings` documents |

**How to embed in Word after Pandoc merge:** Insert → Pictures → one screenshot per page; set **layout** to full width; add **caption** “Figure X — …” for report style and to increase formatted length per college rules.

Save files as:

```
docs/screenshots/01-home.png
docs/screenshots/02-booking.png
…
```
