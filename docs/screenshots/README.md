# Screenshots folder

Place exported **PNG** or **JPG** files here and reference them from your final Word document, or add Markdown image links in a chapter:

```markdown
![Home page](screenshots/01-home.png)
```

This folder is intentionally empty in source control; binary images are usually gitignored for size.

**Tip:** For maximum page count in a printed report, use **one screenshot per page** in Appendix C style with a short caption paragraph under each image.
